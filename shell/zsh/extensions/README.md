# ZSH Extensions Directory

Populate it with local shell scripts and variables that are meant to be auto-included and ignored by git

## Example scripts

- `aliases.zsh`: local aliases
- `functions.zsh`: local functions

## Session environment

### Linux systemd

`environment.conf` is `link.sh` linked config file with systemd syntax.  
It applies to the whole session, including terminals and apps, from the next login on.
